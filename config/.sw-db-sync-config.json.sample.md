# .sw-db-sync-config.json Sample Configuration

Copy `.sw-db-sync-config.json.sample` to your Shopware project root as `.sw-db-sync-config.json` and customize it.

## Configuration Options

### sales_channel_domains
Map sales channel IDs to local domains. Each sales channel can have its own domain.

**Get your sales channel IDs:**
```bash
bin/console sales-channel:list
```

**Example:**
```json
{
  "sales_channel_domains": {
    "018C3C4F4FA170F89E6B5F6A5C8D0E99": "my-store.local",
    "018C3C4F4FA170F89E6B5F6A5C8D0E98": "my-other-store.local"
  }
}
```

### system_config
Set system configuration values per sales channel or globally.

**Use `"null"` or `"global"` as key for global configurations** that apply to all sales channels (not tied to a specific sales channel).

**Example:**
```json
{
  "system_config": {
    "null": {
      "core.basicInformation.email": "info@example.local",
      "core.mailerSettings.emailAgent": "local",
      "core.basicInformation.shopName": "My Local Dev Shop"
    },
    "018C3C4F4FA170F89E6B5F6A5C8D0E99": {
      "core.basicInformation.shopName": "My Local Store",
      "core.basicInformation.email": "store1@example.local"
    }
  }
}
```

## Common System Config Keys

Here are some commonly used system configuration keys:

- `core.basicInformation.email` - Shop email address
- `core.basicInformation.shopName` - Shop name
- `core.mailerSettings.emailAgent` - Email agent (local, smtp, etc.)
- `core.mailerSettings.host` - SMTP host
- `core.mailerSettings.port` - SMTP port
- `core.loginRegistration.passwordMinLength` - Minimum password length
- `core.cart.maxQuantity` - Maximum quantity in cart
